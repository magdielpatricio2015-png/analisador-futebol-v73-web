ANALISADOR FUTEBOL V73 WEB - PRIMEIRA PARTE

1. Extraia esta pasta.
2. Abra o PowerShell dentro da pasta extraída.
3. Instale o Streamlit:

   pip install -r requirements.txt

4. Rode o sistema:

   streamlit run app.py

5. Login inicial:

   usuário: magdiel
   senha: 1234

   usuário: amigo
   senha: 1234

6. Para testar no celular no mesmo Wi-Fi:
   - No PowerShell, digite: ipconfig
   - Procure o IPv4 do seu computador, exemplo: 192.168.0.10
   - No celular, abra: http://192.168.0.10:8501
